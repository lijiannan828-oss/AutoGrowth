# CRF 参数详解：CRF 不是分辨率

## ⚠️ 重要澄清

**CRF (Constant Rate Factor) 不是分辨率设置，也不是编码方式。**

CRF 是 **H.264 编码的质量控制参数**，用于控制视频的质量和文件大小的平衡。

## CRF 的真正含义

### CRF 是什么？

**CRF (Constant Rate Factor)** 是 H.264/x264 编码器的**质量因子**：

- **作用**: 控制视频编码的质量和文件大小的平衡
- **范围**: 0-51
- **值越小**: 质量越高，文件越大
- **值越大**: 质量越低，文件越小

### CRF 与分辨率的关系

**CRF 和分辨率是两个完全独立的参数**：

| 参数 | 作用 | 示例值 |
|------|------|--------|
| **分辨率** | 视频的像素尺寸 | 1920x1080 (1080p), 1280x720 (720p) |
| **CRF** | 视频的质量因子 | 18, 20, 23, 28 |
| **编码器** | 视频编码方式 | H.264 (libx264), H.265 (libx265) |

### 实际关系

**CRF 可以在任何分辨率下使用**：

- **1080p + CRF 23**: 1920x1080 分辨率，CRF 23 质量
- **1080p + CRF 18**: 1920x1080 分辨率，CRF 18 质量（更高）
- **720p + CRF 23**: 1280x720 分辨率，CRF 23 质量
- **720p + CRF 18**: 1280x720 分辨率，CRF 18 质量（更高）

**关键点**: CRF 值不影响分辨率，分辨率也不影响 CRF 值的选择。

## 当前代码中的设置

### FFmpeg 命令分析

```python
cmd = [
    "ffmpeg",
    "-i", video_path.name,           # 输入视频（保持原始分辨率）
    "-vf", "subtitles=...",          # 添加字幕滤镜
    "-c:v", "libx264",                # 视频编码器：H.264
    "-preset", "veryfast",            # 编码速度预设
    "-crf", "23",                     # 质量因子（不是分辨率！）
    "-c:a", "copy",                   # 音频直接复制
    "-movflags", "+faststart",        # Web 优化
    output_path.name,
]
```

**注意**: 
- ❌ **没有设置分辨率参数**（如 `-s 1920x1080`）
- ✅ **保持原始视频的分辨率**
- ✅ **CRF 23 只控制质量，不改变分辨率**

### 分辨率处理

当前代码**保持原始视频的分辨率**：
- 如果原始视频是 1080p，输出也是 1080p
- 如果原始视频是 720p，输出也是 720p
- CRF 值只影响质量，不影响分辨率

## CRF 值的实际效果

### CRF 18 vs CRF 23（相同分辨率）

假设都是 **1080p (1920x1080)** 分辨率：

| CRF | 分辨率 | 质量 | 文件大小 (估算) | 说明 |
|-----|--------|------|----------------|------|
| **18** | 1920x1080 | 极高 | ~40 MB | 接近无损质量 |
| **23** | 1920x1080 | 高 | ~22 MB | 平衡质量和大小 |

**关键**: 分辨率相同，但文件大小和质量不同。

### CRF 与分辨率的关系

**CRF 值的选择应该根据分辨率调整**：

| 分辨率 | 推荐 CRF | 说明 |
|--------|----------|------|
| **4K (3840x2160)** | 18-20 | 高分辨率需要更高质量 |
| **1080p (1920x1080)** | 20-23 | 标准高清，平衡质量 |
| **720p (1280x720)** | 23-28 | 较低分辨率，可以适度压缩 |
| **480p (854x480)** | 28-32 | 低分辨率，可以更大压缩 |

**原因**: 
- 高分辨率视频有更多像素，需要更高质量才能保持清晰
- 低分辨率视频像素较少，可以适度压缩而不明显影响观感

## 总结

### CRF 不是分辨率

- ❌ CRF 18 ≠ 某种分辨率
- ❌ CRF 23 ≠ 某种分辨率
- ✅ CRF 是质量控制参数
- ✅ 分辨率是独立的参数（如 1080p, 720p）

### CRF 的作用

- **控制质量**: CRF 值越小，质量越高
- **控制文件大小**: CRF 值越小，文件越大
- **不影响分辨率**: CRF 值不改变视频的像素尺寸

### 当前代码

- ✅ **保持原始分辨率**: 不改变视频的像素尺寸
- ✅ **CRF 23**: 控制质量和文件大小的平衡
- ✅ **适合 1080p**: 如果视频是 1080p，CRF 23 是标准推荐值
