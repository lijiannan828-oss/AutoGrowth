## CRF 参数影响公式

### 文件大小影响
- **规则**: CRF每减少1，文件大小约增加 **10-15%**
- **公式**: `size_ratio = 1.12^(baseline_crf - target_crf)`
- **示例**: CRF 23 → CRF 20: 文件大小增加约 36%

### 编码时间影响
- **规则**: CRF每减少1，编码时间约增加 **5-10%**
- **公式**: `time_ratio = 1.07^(baseline_crf - target_crf)`
- **示例**: CRF 23 → CRF 20: 编码时间增加约 23%
