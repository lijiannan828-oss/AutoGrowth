# 产品愿景

## 项目概述

**项目名称**: 短剧投放命名与链接自动化生成器 (Short Drama Campaign Naming & Link Automation Generator)

**项目类型**: 内部效率工具

**目标用户**: 短剧营销公司的投放团队（Media Buyers / 投手）

## 愿景陈述

创建一个内部效率工具，消除手动、易出错的 SOP 流程，用于广告系列命名和 OneLink 生成。通过自动化所有数据查询、命名规则应用和链接生成任务，使投手能够 100% 专注于策略优化。

## 目标

### 主要目标
消除当前要求投手执行的"复制-查询-粘贴"手动 SOP 工作流：
- 手动在多个数据表之间交叉查询剧目信息（现统一收敛为 Program Info 表）
- 按照复杂的 SOP 规则手动拼接名称
- 手动构建包含多个参数的 OneLink URL

### 成功指标
- **时间减少**: 将广告系列设置时间从约 10-15 分钟减少到 <30 秒
- **错误减少**: 消除命名和链接生成错误（由于手动流程，当前错误率很高）
- **焦点转移**: 实现 100% 专注于策略优化，而非手动数据录入
- **采用率**: 100% 的投手在所有广告系列创建中使用该工具

## 用户画像

### 主要画像：投手 (Media Buyer)
- **角色**: 广告系列策略师和优化师
- **痛点**:
  - 30-40% 的时间花在手动数据录入而非策略上
  - 经常在命名规范中出错
  - 难以记住复杂的 SOP 规则
  - 对在多个数据源之间反复查找并汇总剧目信息的重复任务感到沮丧
- **目标**:
  - 专注于广告系列性能优化
  - 快速准确地创建广告系列
  - 做出策略决策而无需担心命名规则
- **技术技能**: 基础到中级（熟悉 Web 界面）

## 核心价值主张

1. **零手动查询**: 系统自动从统一维护的 Program Info 表（托管在 Google Sheets）拉取所有剧目信息及 OneLink 模板字段
2. **自动命名**: 按照精确的 SOP 规则生成 Campaign Name、Ad Set Name 和 Ad Name
3. **用户身份识别**: 登录后自动将用户邮箱前缀附加到 Campaign Name 和 Ad Set Name，便于追踪和管理
4. **一键链接生成**: 创建包含所有必需参数的完整 OneLink URL
5. **简单的决策界面**: 用户只需输入策略决策（投哪部剧、哪个国家、优化目标）
6. **即时复制**: 一键复制所有生成的输出

## 用户旅程

### 当前状态（痛苦）
1. 用户需要创建广告系列
2. 打开多个数据表/电子表格（Programs、title_shortener、season_id、OneLink 模板等）
3. 手动搜索 Program Code
4. 汇总 Program Code、Title、SeasonID、program_id、Program shortner、Title(EN/Shortener) 等字段
5. 按照 SOP 规则手动构建 Campaign Name
6. 手动构建 Ad Set Name
7. 手动构建 Ad Name
8. 手动构建包含所有参数的 OneLink URL
9. 验证所有名称是否符合 SOP 规则
10. **时间**: 10-15 分钟，**错误率**: 高

### 未来状态（愉悦）
1. 用户打开 Web 界面
2. 用户登录（使用邮箱账号）
3. 系统展示按上架时间倒序排列的剧目列表，并突出今日上新或热点剧目
4. 用户可直接在列表中点击“去创建广告”进入下一步，也可通过 Program Code / 剧名搜索过滤列表
5. 系统自动识别用户身份，获取登录邮箱前缀
6. 选择剧目后系统自动填充所有相关字段
7. 用户在一个页面填写或调整策略决策（国家、媒体来源、优化等）
8. 用户添加多个 Ad 并填写每个 Ad 的创意特定字段（最多 30 个）
9. 点击"生成"按钮
10. 系统自动将用户邮箱前缀附加到 Campaign Name 和 Ad Set Name
11. 系统显示所有生成结果（1 个 Campaign Name、1 个 Ad Set Name、多个 Ad Name 和对应的 OneLink URL），每个结果带复制按钮
12. 用户逐条复制所有结果并使用
13. **时间**: <30 秒，**错误率**: 零

## 核心功能

### 功能 1：剧目浏览与选择
- 默认展示完整剧目列表，按上架时间/更新时间倒序
- 支持在列表中直接点击“去创建广告”开始配置
- 列表可显示核心信息（海报、剧名、Program Code、上线国家、最新上线时间等）
- 支持通过 Program Code、剧名等关键词过滤列表
- 兼容移动端浏览体验

### 功能 2：智能搜索与联想
- 可通过 Program Code、剧名、别名进行即时搜索
- 搜索结果与列表联动，高亮匹配项
- 支持模糊匹配、拼音/英文缩写

### 功能 3：统一策略配置表单
- **统一页面**: 在一个页面中完成 Campaign、Ad Set、Ad 的所有策略配置
- **广告系列级别**: 国家、媒体来源、市场类型、目标类型、优化类型、操作系统、事件类型、备注
- **广告组级别**: 可选标识符（必填）
- **广告级别**: 支持动态添加多个 Ad（最多 30 个），每个 Ad 包含创意类型、编号、介绍集数、包含文本、概念关键词、语言
- 智能验证和条件字段
- 明确呈现当前选中的剧目信息，支持返回列表重新选择

### 功能 4：用户登录与身份识别
- 用户使用邮箱账号登录系统
- 系统自动提取登录邮箱的前缀部分（@ 符号前的部分）
- 登录状态持久化，用户无需重复登录
- 支持登出功能

### 功能 5：自动名称生成
- Campaign Name：遵循精确的 SOP 拼接规则，自动附加用户邮箱前缀作为可选字段（1 个）
- Ad Set Name：基于 Campaign Name + 标识符，自动附加用户邮箱前缀作为可选字段（1 个）
- Ad Name：遵循精确的 SOP 规则，智能跳过字段（不附加邮箱前缀），为每个配置的 Ad 生成一个独立的 Ad Name（最多 30 个）
- 所有名称保证符合 SOP 标准
- 邮箱前缀格式：从用户登录邮箱中提取（例如：user@company.com → user）

### 功能 6：OneLink URL 批量生成
- 为每个 Ad 自动生成对应的完整 OneLink URL
- 从生成的名称自动构建参数
- 包含所有必需的查询参数
- 遵循 onelink生成 表中的精确模板
- OneLink URL 数量与 Ad Name 数量完全一致（最多 30 个）
- 即用型 URL 格式

### 功能 7：逐条复制
- 每个生成输出的独立复制按钮
- 即时剪贴板复制
- 成功复制的视觉反馈
- 支持滚动查看所有结果并逐条复制

## 非目标

- **不是广告系列管理平台**: 此工具仅生成名称和链接，不管理广告系列
- **不是报告工具**: 无分析或性能跟踪
- **不是多用户协作工具**: 专注于个人生产力
- **不是数据管理工具**: 假设数据表在其他地方维护
- **不是完整的用户管理系统**: 登录功能仅用于身份识别和名称前缀附加，不包含复杂的权限管理

## 约束与假设

### 约束
- Program Info 表托管在 Google Sheets，需保证 API 访问权限与速率限制
- SOP 命名规则是固定的，不能更改
- OneLink 模板格式是固定的（存储在 Program Info 表或配置中）
- 必须在浏览器环境中工作
- 后端需可连接 GCP Cloud SQL（PostgreSQL）用于用户与缓存数据

### 假设
- 投手可以访问 Web 浏览器
- Google Sheets（Program Info 表）定期准确更新，并提供服务账号访问凭证
- SOP 规则有良好文档且稳定
- 用户理解他们需要做出的策略决策
- 用户拥有有效的邮箱账号用于登录
- 邮箱前缀格式统一且可提取（@ 符号前部分）
- GCP 基础设施（Firebase Hosting、Cloud Run、Cloud SQL）可用且按需扩展
