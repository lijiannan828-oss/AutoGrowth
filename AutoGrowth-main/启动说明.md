# 项目启动说明

## 后端启动

```bash
# 方式1: 使用批处理文件（推荐）
cd "d:\AutoGrowth-main (1)\AutoGrowth-main\backend"
.\start_backend.bat

# 方式2: 手动启动
cd "d:\AutoGrowth-main (1)\AutoGrowth-main\backend"
python -m uvicorn app.main:app --reload --port 8001
```

后端地址: http://localhost:8001

## 前端启动

```bash
# 进入前端目录
cd "d:\AutoGrowth-main (1)\AutoGrowth-main\frontend"

# 启动开发服务器
npm run dev
```

前端地址: http://localhost:3000

## 常见问题

### 1. npm run dev 报错找不到 package.json
**原因**: 在错误的目录运行命令
**解决**: 必须先 `cd` 到 `frontend` 目录

### 2. 后端启动失败
**原因**: 可能缺少依赖或环境变量
**解决**: 
- 检查 Python 环境
- 安装依赖: `pip install -r requirements.txt`
- 配置 `.env` 文件

### 3. TTS 功能无法使用
**原因**: 后端 API 路径需要包含 `/api/v1`
**解决**: 已修复，前端会自动调用正确的 API 路径
