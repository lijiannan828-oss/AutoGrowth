# FE-013-5 健壮性增强测试指南

## 实现说明

已实现健壮性增强功能，包括重试机制、错误分类和失败文件列表弹窗。

### 核心改进

1. **重试机制**:
   - 网络类错误（fetch 抛错、5xx）指数退避重试 3 次
   - 初始延迟 1 秒，最大延迟 10 秒，退避倍数 2
   - 文件系统权限错误不重试，直接失败

2. **错误分类**:
   - 网络错误：5xx、429、fetch 失败、超时等（可重试）
   - 文件系统权限错误：NotAllowedError、SecurityError 等（不可重试）

3. **失败文件列表弹窗**:
   - 下载完成后自动显示失败文件列表
   - 支持导出失败日志（TXT 文件）
   - 支持重试失败项

### 预期效果

- **网络错误恢复**: 临时网络问题自动重试，提高成功率
- **错误处理**: 区分可重试和不可重试错误，避免无效重试
- **用户体验**: 失败文件清晰展示，支持导出和重试

## 测试步骤

### 1. 测试网络错误重试

**场景**: 模拟网络错误，验证重试机制

1. 打开浏览器开发者工具（F12）
2. 切换到 Network 标签
3. 选择 "Offline" 或 "Slow 3G" 模式
4. 开始下载文件
5. 观察控制台日志

**预期结果**:
- 应该看到重试日志：
```
[Download] FE-013-5: 网络请求失败: ... (已重试 3 次)
```
- 如果网络恢复，文件应该成功下载
- 如果网络持续失败，文件标记为失败

### 2. 测试文件系统权限错误

**场景**: 模拟文件系统权限错误，验证不重试

1. 开始下载文件
2. 在文件系统权限提示时选择"拒绝"
3. 观察控制台日志

**预期结果**:
- 应该看到权限错误日志：
```
[Download] FE-013-5: 文件系统权限错误: ...
```
- 不应该看到重试日志（权限错误不重试）
- 文件立即标记为失败

### 3. 测试失败文件列表弹窗

**场景**: 下载完成后有失败文件，验证弹窗显示

1. 开始下载多个文件（建议 10+ 个文件）
2. 模拟部分文件失败（网络错误或权限错误）
3. 等待下载完成
4. 观察是否显示失败文件列表弹窗

**预期结果**:
- 下载完成后自动显示失败文件列表弹窗
- 弹窗显示失败文件数量和详细信息
- 每个失败文件显示路径和错误信息

### 4. 测试导出失败日志

**场景**: 导出失败文件列表为日志文件

1. 在失败文件列表弹窗中点击"导出失败日志"
2. 检查下载的文件

**预期结果**:
- 自动下载 TXT 文件（文件名：`download-failures-{timestamp}.txt`）
- 文件内容包含：
  - 生成时间
  - 失败数量
  - 每个失败文件的路径和错误信息

### 5. 测试重试失败项

**场景**: 重试失败的下载项

1. 在失败文件列表弹窗中点击"重试失败项"
2. 观察是否启动新的下载任务

**预期结果**:
- 弹窗关闭
- 启动新的下载任务
- 只下载之前失败的文件
- 控制台显示重试日志：
```
[Download] FE-013-5: 重试失败文件 - X 个文件
```

## 性能指标

### 预期改进

- **网络错误恢复率**: 临时网络问题自动恢复，减少手动重试
- **错误分类准确性**: 正确区分可重试和不可重试错误
- **用户体验**: 失败文件清晰展示，支持导出和重试

### 重试策略

- **初始延迟**: 1 秒
- **最大延迟**: 10 秒
- **退避倍数**: 2
- **最大重试次数**: 3 次
- **总等待时间**: 最多约 7 秒（1 + 2 + 4 = 7 秒）

## 故障排查

如果发现重试未生效：

1. **检查日志**: 确认是否看到"FE-013-5"相关日志
2. **检查错误类型**: 确认错误是否为网络错误（5xx、fetch 失败等）
3. **检查重试次数**: 确认是否达到最大重试次数（3 次）

如果发现失败文件列表弹窗未显示：

1. **检查任务状态**: 确认任务状态为 "COMPLETE"
2. **检查失败文件**: 确认 `failedFiles` 数组不为空
3. **检查弹窗状态**: 确认 `showFailureModal` 为 true
