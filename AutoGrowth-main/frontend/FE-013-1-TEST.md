# FE-013-1 目录句柄缓存测试指南

## 实现说明

已实现目录句柄缓存功能，用于减少 `getDirectoryHandle` 调用次数。

### 核心改进

1. **缓存存储**: 使用 `useRef<Map<string, FileSystemDirectoryHandle>>` 存储目录句柄
2. **路径标准化**: 实现 `normalizePath` 函数，统一处理路径格式（去除多余斜杠）
3. **缓存查找**: 在创建目录前先检查缓存，命中则直接使用
4. **缓存写入**: 创建新目录后立即写入缓存

### 预期效果

对于 6000 个文件分布在 100 个文件夹中的场景：
- **优化前**: 每个文件都需要调用 `getDirectoryHandle`，约 6000 次调用
- **优化后**: 每个目录只调用一次 `getDirectoryHandle`，约 100 次调用
- **减少比例**: 90%+ 的调用减少

## 测试步骤

### 1. 准备测试数据

在资源库页面选择包含多个文件的目录，例如：
- 选择一个剧集目录（包含多个语言文件夹，每个语言文件夹包含多个集数）
- 建议选择至少 50+ 文件的目录进行测试

### 2. 开始下载

1. 打开浏览器开发者工具（F12）
2. 切换到 Console 标签
3. 在资源库页面选择要下载的目录
4. 点击"下载"按钮
5. 选择保存位置

### 3. 观察控制台日志

在下载过程中，观察控制台输出：

**缓存命中日志**（应该频繁出现）:
```
[Download] 缓存命中: drama_name/lang
[Download] 缓存命中: drama_name/lang/episode
```

**缓存未命中日志**（只在首次创建目录时出现）:
```
[Download] 创建/获取目录并缓存: drama_name
[Download] 创建/获取目录并缓存: drama_name/lang
```

### 4. 验证缓存效果

**预期行为**:
- 对于同一目录下的多个文件，应该看到多次"缓存命中"日志
- 每个目录路径只应该看到一次"创建/获取目录并缓存"日志
- 例如：如果有 50 个文件都在 `drama_name/lang/` 目录下，应该看到：
  - 1 次 `创建/获取目录并缓存: drama_name`
  - 1 次 `创建/获取目录并缓存: drama_name/lang`
  - 48 次 `缓存命中: drama_name/lang`（第一个文件创建目录，后续 49 个文件使用缓存）

### 5. 性能对比（可选）

如果需要对比性能，可以：
1. 临时注释掉缓存逻辑，记录下载时间
2. 恢复缓存逻辑，再次记录下载时间
3. 对比两次的下载时间和控制台中的 `getDirectoryHandle` 调用次数

## 测试检查清单

- [ ] 缓存命中日志正常显示
- [ ] 每个目录路径只创建一次（通过日志确认）
- [ ] 下载功能正常（文件正确保存到对应目录）
- [ ] 目录结构正确（与 GCS 中的结构一致）
- [ ] 没有出现目录创建错误
- [ ] 控制台没有缓存相关的错误信息

## 已知限制

- 缓存仅在单次下载会话中有效（每次下载开始时清空）
- 缓存不会跨下载会话持久化（符合预期，因为每次下载可能选择不同的根目录）

## 故障排查

如果发现缓存未生效：

1. **检查控制台日志**: 确认是否看到"缓存命中"日志
2. **检查路径标准化**: 确认 `normalizePath` 函数正确处理了路径格式
3. **检查缓存键**: 在控制台添加日志，打印缓存键和缓存大小
4. **检查浏览器支持**: 确认浏览器支持 File System Access API
