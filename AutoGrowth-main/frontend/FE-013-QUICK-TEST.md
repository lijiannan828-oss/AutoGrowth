# FE-013 快速测试指南（重点：FE-013-6 竞态条件）

## 🎯 核心测试目标

验证 FE-013-6 竞态条件修复是否生效：**在快速下载 + 慢速 API 场景下，不会提前完成，所有文件都能下载**。

## ⚡ 快速测试步骤（5 分钟）

### 1. 准备工作

```bash
# 确认前端服务运行
lsof -i :3001 | grep LISTEN || echo "需要启动前端服务"
```

### 2. 关键测试（FE-013-6）

1. **打开浏览器**: http://localhost:3001/pipeline/library
2. **打开开发者工具** (F12):
   - Console 标签
   - Network 标签
3. **设置网络节流**:
   - Network 标签 → 点击 "No throttling" → 选择 **"Slow 3G"**
4. **选择测试数据**:
   - 选择一个包含 **500+ 个文件** 的目录
5. **开始下载**:
   - 选择文件/目录
   - 点击"下载"
   - 选择保存位置
6. **观察关键日志**:

**✅ 应该看到**:
```
[Download] FE-013-6: 等待中... (队列空闲但正在获取: true, 还有批次: true, 剩余路径: XXX)
```

**❌ 不应该看到**:
- 队列为空时立即显示"下载完成"
- 实际下载文件数 < 期望文件数
